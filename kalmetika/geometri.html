Barisan & Deret Geometri

Barisan geometri mempunyai rasio tetap antara satu suku dengan suku berikutnya.

Rumus Barisan Geometri

Un = a × r^(n - 1)
a
Suku pertama
r
Rasio
n
Nomor suku
Un
Suku ke-n

Contoh Barisan

2, 6, 18, 54, 162, ...

✓6 / 2 = 3
✓18 / 6 = 3
✓54 / 18 = 3
Jadi r = 3. Karena rasio tetap, barisan tersebut adalah barisan geometri.
Deret Geometri

Jumlah n suku pertama

Sn = a(r^n - 1)/(r - 1)

Gunakan bentuk ini untuk r ≠ 1. Bentuk ekuivalennya adalah Sn = a(1 - r^n)/(1 - r).

Contoh 1 — Jumlah 5 suku

Tentukan jumlah 5 suku pertama dari 2 + 6 + 18 + 54 + ...

Diketahui: a = 2, r = 3, n = 5.
S5 = 2(3^5 - 1)/(3 - 1)
S5 = 2(243 - 1)/2
S5 = 242

Jawaban: Jumlah 5 suku pertama = 242.

Contoh 2 — Mencari U5

Diketahui a = 2, r = 3. Tentukan U5.

Diketahui: a = 2, r = 3, n = 5.
U5 = 2 × 3^(5 - 1)
U5 = 2 × 3^4
U5 = 2 × 81 = 162

Jawaban: U5 = 162.

Contoh 3 — Jumlah 3 suku pertama

Tentukan S3 dari 5 + 10 + 20 + ...

Diketahui: a = 5, r = 2, n = 3.
S3 = 5(2^3 - 1)/(2 - 1)
S3 = 5(8 - 1)
S3 = 35

Jawaban: Jumlah 3 suku pertama = 35.
