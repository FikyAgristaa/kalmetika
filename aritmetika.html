Barisan & Deret Aritmetika

Barisan aritmetika memiliki selisih (beda) yang sama pada setiap sukunya. Deret aritmetika adalah penjumlahan suku-suku tersebut.

Rumus Barisan Aritmetika

Un = a + (n - 1)b
a
Suku pertama
b
Beda
n
Nomor suku
Un
Suku ke-n

Contoh Barisan

2, 5, 8, 11, 14, ...

✓5 − 2 = 3
✓8 − 5 = 3
✓11 − 8 = 3
Jadi b = 3. Karena beda tetap, barisan tersebut adalah barisan aritmetika.
Deret Aritmetika

Jumlah n suku pertama

Sn = n/2 × (2a + (n - 1)b)

Deret aritmetika adalah penjumlahan suku pada barisan aritmetika. Contoh: 2 + 5 + 8 + 11 + 14.

Contoh 1 — Jumlah 5 suku pertama

Tentukan jumlah 5 suku pertama dari barisan 2, 5, 8, 11, ...

Diketahui: a = 2, b = 3, n = 5.
S5 = 5/2 × (2(2) + (5 - 1)3)
S5 = 5/2 × (4 + 12)
S5 = 5/2 × 16
S5 = 40

Jawaban: Jumlah 5 suku pertama = 40.

Contoh 2 — Mencari suku ke-10

Diketahui a = 3 dan b = 4. Tentukan U10.

Diketahui: a = 3, b = 4, n = 10.
U10 = 3 + (10 - 1)4
U10 = 3 + 36
U10 = 39

Jawaban: U10 = 39.

Contoh 3 — Jumlah 10 suku

Diketahui a = 3, b = 4. Tentukan S10.

Diketahui: a = 3, b = 4, n = 10.
S10 = 10/2 × (2(3) + (10 - 1)4)
S10 = 5 × (6 + 36)
S10 = 5 × 42
S10 = 210

Jawaban: Jumlah 10 suku pertama = 210.
